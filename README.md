## 🚀 Featured Projects

### 🎬 Critix: Movie Review & Community Platform
[**🔗 Live Demo**](https://critix-review.vercel.app/)

A full-stack platform where users browse, rate and review movies, with threaded replies, likes, watchlists, notifications and content reporting. Includes a custom-built admin portal with a dashboard, moderation tools, staff access control, bulk actions and CSV/Excel import/export.

`Django` `PostgreSQL` `JavaScript` `Vercel`

### 💼 Career Portal: Recruitment & Resume-Screening Platform
A Django hiring platform with separate HR/Recruiter and Candidate roles. It includes job posting, applications, a talent pool, interview scheduling and offer letters, plus an automated resume-screening engine that parses resumes and job descriptions and scores candidates using TF-IDF/cosine similarity. Scanned resumes are handled with OpenCV and Tesseract OCR.

`Django` `SQLite` `OpenCV` `Tesseract OCR` `PyMuPDF`

### 👁️ Object Detection & Image Processing Toolkit
A Flask web app that exposes many OpenCV image and video operations through a browser UI, including edge detection, thresholding, background removal, template matching and frame extraction. Face and eye detection runs on uploaded videos using a Caffe ResNet-10 SSD model with Haar cascades, streamed frame by frame.

`Flask` `OpenCV` `Tesseract OCR` `ReportLab`

### 📄 Smart Document Scanner
Turns photographed documents into clean scanned PDFs using an OpenCV pipeline (edge detection, perspective correction, shadow removal and denoising), classifies the document type, extracts text with Tesseract OCR, and includes an offline extractive text summarizer.

`Flask` `OpenCV` `Tesseract OCR`

### 🎨 Meslova CSR Website (Front-End, Team Project)
Designed and built the complete front end for the public and admin pages of Meslova Systems' CSR platform, including a custom "Premium Luxury" design system with responsive layouts, animations and a lightbox gallery.

`HTML` `CSS` `JavaScript` `jQuery` `Bootstrap` `Django Templates`
