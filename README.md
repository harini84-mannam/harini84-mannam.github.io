# Harini Mannam Portfolio

A premium dark developer portfolio built from the supplied resume and portfolio brief. It uses semantic HTML, modern CSS, and vanilla JavaScript with no build step or runtime dependencies.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Included

- Responsive sticky navigation with mobile hamburger menu
- Developer-themed terminal hero with floating technology badges
- About, skills, internship experience, education, achievements, projects, code CTA, and contact sections
- Filterable project grid with expandable case-study modals
- Resume download using the supplied `Harini_Mannam_Resume_Updated.docx`
- Contact form validation with a mailto success flow
- Smooth scrolling, reveal animations, hover states, focus states, and reduced-motion support
- SEO metadata, Open Graph metadata, inline favicon, and accessible semantic structure

The LinkedIn and GitHub buttons currently link to the platform homepages because personal profile URLs were not included in the supplied content. Replace those URLs in `index.html` when the exact profiles are available.
