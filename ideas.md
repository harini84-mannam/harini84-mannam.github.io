# Harini Mannam Portfolio — Design Brief

## Direction shortlist
- **Signal / Graphite** — editorial portfolio with hard edges, data-like accents, and a lime signal color. Probability: 0.07
- **Plum / Paper** — warm creative-tech portfolio pairing an ivory paper field with deep plum, coral, and a quiet grid. Probability: 0.06
- **Midnight / Terminal** — dark developer portfolio with electric blue and utility panels. Probability: 0.05

## Committed direction: Plum / Paper

- **Design movement:** editorial creative-tech; precise enough for engineering, warm enough for a personal portfolio.
- **Core principles:** show technical range without looking like a generic template; make projects scannable; create clear recruiter paths.
- **Color philosophy:** ivory background, near-black ink, deep plum anchors, coral action color, acidic lime for small technical signals.
- **Layout paradigm:** asymmetric hero, sticky side rail on desktop, modular project cards, strong vertical rhythm, responsive single-column fallback.
- **Signature elements:** oversized outlined initials, small numbered labels, hairline rules, pill-like project tags, paper-grain illusion from layered gradients.
- **Interaction philosophy:** low-friction navigation; filters reveal project clusters; motion is subtle and purposeful.
- **Animation:** rise-in section reveal, hover lift on cards, active nav state, filter transitions.
- **Typography system:** Space Grotesk for display/body, IBM Plex Mono for metadata and labels.
- **Brand essence:** builder of useful systems at the intersection of web development, computer vision, and thoughtful UX.
- **Brand voice:** clear, curious, grounded, quietly ambitious.
- **Wordmark/logo:** HM monogram built from two offset brackets, rendered as an inline mark so it remains sharp at any size.
- **Signature brand color:** coral `#ff7043`.
